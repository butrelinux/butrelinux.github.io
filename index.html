01 — THE IDEA

A solid base.
Room to choose.

Butrelinux brings an image-based operating system and a familiar desktop together, with multi-user Nix integration and choices over the kernel that powers your hardware.

01
▧

Image-based by design

Built as a bootc image on CentOS Stream 10. The operating system is delivered as an image rather than assembled as a traditional mutable install.

02
⌘

Kernel choice

Choose from the stock kernel, CachyOS LTO, ELRepo kernel-ml, or the Hyperscale SIG kernel—with NVIDIA variants where provided.

03
▦

KDE Plasma desktop

A desktop-focused system with KDE Plasma at its center, built on the CentOS Stream 10 ecosystem.

04
◇

Signed images

Container images are signed with Sigstore Cosign, so you can verify the image signature before switching to it.

YOUR IMAGE

lts

Stock CentOS Stream 10 kernel (6.12). No additional kernel modules or NVIDIA support.

CONTAINER IMAGE

ghcr.io/butrelinux/lts:latest

REBASE COMMAND

sudo bootc switch --enforce-container-sigpolicy ghcr.io/butrelinux/lts:latest --apply

For existing compatible EL10 bootc systems. Read the prerequisites before switching.

Hardware support varies. For older nvidia GPUs using the nouveau driver, use the standard non-nvidia variant of your choice. These images are built for x86_64-v3 architecture only.

EXISTING BOOTC USERS02
⌁

Switch an existing system

For compatible CentOS Stream-derived EL10 bootc systems, use the command for your selected image.

sudo bootc switch --enforce-container-sigpolicy ghcr.io/butrelinux/lts:latest --apply

Important: Rebasing from Fedora is not recommended, as cross-rebasing can leave incompatible system states. CentOS Stream-derived distros such as HeliumOS or CentOS Bootc are supported. Back up important data and read the project instructions first.
